# Personal Profile Web Application (CSC584 Individual Assignment 1)

## Project Description
This is a simple Java Web Application developed using HTML, CSS, Java Servlets, and JavaServer Pages (JSP). It collects personal profile information from a user via an HTML form, submits the data using an HTTP POST request to a Java Servlet, and displays the processed profile details cleanly on a JSP page.

## Technologies Used
- **Frontend:** HTML5, CSS3
- **Backend:** Java Servlet (Java EE 7)
- **View Layer:** JSP (JavaServer Pages)
- **IDE:** NetBeans IDE 8.2
- **Server:** GlassFish Server / Apache Tomcat

## Application Flow
`index.html` (HTML Form) ➔ `ProfileServlet.java` (HTTP POST) ➔ `profile.jsp` (Output Display)
